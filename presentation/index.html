01 · Naming

One light in. A spectrum out.

A prism takes a single beam and reveals the spectrum that was always inside it. PRISMA does the same with a client's question: one problem statement goes in, and the full range of what Nextant has already built comes out — split across its three Specialization Areas.

click the prism · the metaphor is also the information architecture

It's about revelation

The library doesn't create the work — it makes visible what was already there, scattered across machines, channels, and memory.

It's about light

Light is the raw material of the whole visual system: the aurora ground, the glass surfaces, the sheen. The name sets up the material.

It sits beside Nextant

Short, international, pronounceable in every language the team speaks. A product name, not a department acronym.

02 · Brand lineage

The Nextant blue, treated as light

The base colour is lifted straight from the Nextant wordmark — steel blue #1C567C. The modernization isn't a new palette; it's a new treatment: instead of using the blue as paint, PRISMA uses it as a light source. In dark theme it brightens into a luminous #7FB6D9; in light theme the original steel blue carries the accent itself.

Continuity, not rebrand

Everyone inside Nextant should feel the family resemblance instantly. The hue never changes — only its luminosity and role adapt per theme.

Contrast is a hard rule

Every accent pairing must pass WCAG AA in both themes. The dark-theme brightening of the blue is a contrast decision as much as an aesthetic one.

03 · Light

Glass needs something to refract

Beneath every surface sits the aurora ground: three large colour fields — one per Specialization Area — blurred over 100px, over a near-black (or paper-light) base, with a hairline grid fading in from the top. Without it, backdrop blur has nothing to work with and every glass panel reads as flat grey. The aurora is the reason the glass feels alive.

AI field

Top-left. The accent-blue blob anchors the brand colour into the environment itself.

IBO field

Right edge. Violet keeps the ground from reading monochrome and cold.

Data field

Bottom. Teal completes the spectrum — the prism metaphor rendered as environment.

Deliberately static

The fields do not animate. Every glass panel above them re-blurs its backdrop when the backdrop changes — animating the aurora would force a full-screen re-blur on every frame. Perceived motion comes from you scrolling glass over the field, not from the field moving. This is a performance decision disguised as a calm aesthetic.

05 · Refraction

What makes it liquid, not frosted

Frosted glass just blurs. Liquid glass bends. An SVG displacement map (fractal noise → soft blur → displacement) sits in the backdrop-filter chain and warps the blurred aurora at the surface — the subtle waviness of looking through old window glass.

FROSTED · blur only

Blur + saturate. Clean, but inert — the backdrop is smoothed into fog.

LIQUID · blur + displacement

The displacement map bends the light field at the surface — the pane gains optics.

Gated at runtime

SVG displacement inside backdrop-filter only renders on Chromium — elsewhere it can invalidate the whole chain and kill the blur. So refraction is feature-detected and applied as a progressive enhancement, never assumed.

Spent where it shows

Large repeated surfaces (the card grid) opt out via a "lite" variant: per-frame displacement during scroll costs more than it shows. The effect is a spice, budgeted like one.

The dark→light shift is a physics change

In dark theme, colours are emitters — bright, luminous, low-saturation fills over near-black. In light theme they become pigments — deep, ink-like, sitting on paper. Same identities, different physics. And every pairing passes WCAG AA contrast in both.

08 · Motion & accessibility

Purposeful motion, universal access

Motion is short and semantic — it explains a state change, then gets out of the way. Nothing decorative sits on the CSM hero path, because that path is used live in front of clients.

Two easings, two meanings

Sheets and panels use a decisive settle; small interactive elements get a spring with a hint of overshoot — glass has mass.

sheet

--ease-sheet · cubic-bezier(0.32, 0.72, 0, 1)

sprg

--ease-spring · cubic-bezier(0.34, 1.56, 0.64, 1)

The sheen follows your pointer

Small interactive panels track the cursor with a specular highlight — a single delegated, frame-throttled listener writing two CSS variables. Light on a curved surface, computed for pennies.

Reduced motion is honoured, structurally

prefers-reduced-motion disables the shimmer, the sheen tracking, and non-essential transitions — including in this deck. Not an option buried in settings; a media query obeyed everywhere.

WCAG 2.1 AA is a floor

Full keyboard navigation, visible :focus-visible rings in accent colour, semantic landmarks, contrast verified per theme. Try tabbing through this deck.

10 · Frameworks

Chosen for the constraint, not the résumé

PRISMA ships as a Power Apps code app — full custom code, delivered inside the Power Platform with Entra ID SSO and Dataverse behind it. That constraint drove every framework choice.

UI

React 19 + TypeScript

Component model matches the design system's component thinking; strict types mirror the Dataverse schema so the mock data and the future live data share one shape.

Build

Vite

Instant feedback while tuning glass and motion — a design system this optical is built by looking, and the loop has to be seconds.

Styling

Tailwind v4 + CSS tokens

All identity lives in CSS custom properties (theme-swappable at the root); Tailwind handles layout. The glass surfaces are hand-written CSS — some things deserve prose.

Platform

Power Apps code app

Published under the tenant's /play/… path — which dictates hash-based routing and relative asset paths. Real constraints, designed for from day one.

Data

Dataverse

Single source of truth: solutions, demo assets, images, and governed reference data. The UI is built against its exact shape so the swap-in is a data-layer change, not a redesign.

Identity

Entra ID SSO

Internal users only; clients never hold a credential. The CSM is always the authenticated driver — presenting is screen-sharing, never sharing access.

11 · Principles

The rules the design will not break

Aesthetics can evolve; these cannot. They are the contract between the design and the moment it exists for — a CSM live on a client screen.

Present mode restricts — it never merely hides

Client-safe filtering happens before anything renders, never as cosmetic hiding. If it's not safe to show, it isn't in the room.

Redaction is data, not string-scrubbing

Client-sensitive text lives in a dedicated redacted field. Safety is structural, never a runtime find-and-replace.

Untrusted content stays behind glass — literally

User-supplied demo HTML renders only inside a sandboxed frame with no access to the host app.

The hero flow is sacred

Search → grid → detail → viewer stays fast and unobstructed. Any addition to that path has to earn its click.
